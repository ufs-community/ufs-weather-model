# UFS-Coastal LICENSE file (derived from UFS Weather Model)

## 1. Overview

The UFS-Coastal system is a coupled modeling framework that integrates multiple numerical models developed by external teams. This project includes:

- Third-party open-source components, governed by their original licenses (see Section 2)

- Original coupling code developed by the UFS-Coastal team (see Section 3)

- U.S. Government contributions, which are in the public domain (see Section 4)
